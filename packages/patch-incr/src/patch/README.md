# Patch application
 
Patch-based incremental computation requires a type `DT` to represent the changes made to
data of type `T`. 

Given the patch target type `T`, there is the universal patch type `Patches<T>` 
and the universal patch application function `applyPatches`. 

Without the type parameter, `Patches` represents `Patches<any>`.

## Design

In JavaScript and TypeScript a __universal patch type__ simplifies the type checking and
the evaluation of incremental functions.

The `Patches<T>` type is based how JSON Patches are patches generated by 
the [Immer](https://immerjs.github.io/immer/patches) library under extensions:
 - `enablePatches()`
 - `enableMapSet()`

The `applyPatches` function is a drop-in replacement for Immer's `applyPatches`.

## The patch type
`Patches<T>` is a list of `PatchEntry<T>` resembling Immer's patches.

A `PatchEntry<T>` is a type alias for the sub-type of patch entries:
 - `PatchAdd`
 - `PatchRemove`
 - `PatchReplace`
 
```typescript
interface PatchEntry<T> {
  op: PatchOp,
  path: Path,
  value: unknown,
}
```

## Extended patches

Extend patches contain patch operations not supported by Immer: copy, move and swap.

Type type for extended patches is `PatchesExtended<T>`, which contains entries of
`PatchEntryExtended<T>`. The additional patch entries are:
 - `PatchCopy`
 - `PatchMove`
 - `PatchSwap`

The `patch-incr` library is currently not designed to `derive` these patches.
Incremental functions will fail or defer to `evaluate` when these patches are used.

## Applicable target types

The replace-root patch `[{ op: PatchOp.Replace, path: [], value: ... }]`
is applicable for all types including primitives and functions.

 - Plain objects
 - Arrays
 - `Map`
 - `Set`

## Applying patches

The `applyPatches` function returns a new value with the patches applied.
The `applyGet` function performs path access on a value, and that is how
`applyPatches` handles path access.

```typescript
const value = { age: 33 }

const patches: Patches<typeof value> = [ 
  { op: PatchOp.Replace, path: ['age'], value: 34 }
]

// { age: 34 }
const changed = applyPatches(value, patches)

// 33
const getByPath = applyGet(value, ['age'])
```

## Compatibility with Immer and JSON Patches

Departures from how Immer handles patching are:
 - Doing `remove` on root sets the root to undefined
 - `copy`, `move` and `swap` are supported

Departures from JSON patches are:
 - The `test` operation is not supported
 - Pure string paths are not supported
 - There is a `swap` operation that behaves like two simultaneous `move` operations
